A one-line tombstone epitaph of famous last words for make.fun's "Famous Last Words: The Funniest Epitaph" bounty — black comedy carved in stone. The program writes a single dying line to `/output/entry.txt`: the classic "Here lies..." opener, then the twist — the man died exactly as he lived, avoiding small talk to the very end. A whole life summed up in one habit, and the habit follows him into the grave.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

The program needs Node 22 or later and writes exactly one line (58 characters, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
